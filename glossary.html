术语索引

系统提示词 · systemPrompt

作为请求 system 参数发送的文本。用户上下文另用 meta 用户消息传递，角色不因 system-reminder 标签而改变（utils/api.ts:437-474）。见第 1 章。

用户上下文 · userContext

初始 CLAUDE.md 与日期等键值经 prependUserContext 前置到消息列表；自定义系统提示词不会自动关闭其取得（utils/queryContext.ts:60-74）。见第 1 章、第 3 章。

本地段缓存 · systemPromptSection

按段名复用计算结果，与 API 请求中的 cache_control 分开说（constants/systemPromptSections.ts:16-68）。见第 2 章。

动态边界 · SYSTEM_PROMPT_DYNAMIC_BOUNDARY

客户端分隔全局缓存前缀的标记，实际构造文本块时剥离（utils/api.ts:362-410）。见第 2 章。

附件 · attachment

全书统一用“附件”，不用“附属”。指令延迟加载的 nested_memory 附件会转为带来源的 meta 用户消息（utils/attachments.ts:1709-1775、utils/messages.ts:3700-3707）。见第 3 章、第 16 章。

工具描述 · prompt / description

API 工具 description 来自 Tool.prompt；Tool.description 是接收具体输入的另一方法（Tool.ts:386-406、Tool.ts:518-524、utils/api.ts:169-178）。见第 7 章。

延迟加载 · defer_loading

名称发现与完整 schema 加载分开，alwaysLoad 与特定工具豁免须带条件（tools/ToolSearchTool/prompt.ts:53-117）。见第 7 章。

判定 · PermissionDecision

全书统一用“判定”，不用“裁决”指代同一结果。allow、deny、ask 是权限行为，passthrough 在主规则管线末尾归一为 ask（utils/permissions/permissions.ts:1283-1319）。见第 10 章。

影响范围 · blast radius

原文与可逆性一起要求模型核对动作的影响对象；全书统一译作“影响范围”（constants/prompts.ts:258-266）。见第 4 章。

权限模式 · permission mode

类型、当前可用性和一次输入的实际判定分开说；auto 另受构建与配置条件控制（types/permissions.ts:16-36）。见第 11 章。

hook · PreToolUse / PermissionRequest

保留英文事件名。前者在工具执行前可改输入并复查规则，后者在请求许可阶段可给决定与规则更新（services/tools/toolHooks.ts:321-393、utils/permissions/permissions.ts:393-446）。见第 12 章。

沙箱 · sandbox

权限判定与执行环境分开解释，当前树只追踪到 BaseSandboxManager 委派（utils/sandbox/sandbox-adapter.ts:704-725）。见第 13 章。

上下文窗口 · context window

本地窗口选择与服务端模型能力分开，默认值与环境覆盖都要带条件（utils/context.ts:8-16、utils/context.ts:27-112）。见第 14 章。

整轮目标 · TOKEN_BUDGET

通过继续消息要求更多工作；不同于窗口大小和 API task_budget（query/tokenBudget.ts:45-93）。见第 14 章。

压缩 · compact / microcompact

整段摘要与工具结果微压缩分别命名，调用顺序由 query 明确安排（query.ts:365-468）。见第 15 章。

会话笔记 · session memory

当前会话的维护文件，抽取回调只放指定路径的 Edit（services/SessionMemory/sessionMemory.ts:457-495）。见第 15 章、第 16 章。

持久记忆 · auto memory

跨会话目录与索引，不等于所有抽取或预取默认启用。MEMORY.md 的命名字节限制实际用字符串长度（memdir/memdir.ts:34-103）。见第 16 章。

团队记忆 · team memory

共享内容另有类型范围、写入检查与同步条件；注释说本地删除不传播（services/teamMemorySync/index.ts:1-25）。见第 16 章。
