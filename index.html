阅读约定

这本书从指定源码树解释模型收到什么指令、工具怎样描述调用流程、权限怎样判定，以及上下文怎样回收和保存。正文未标记的论述默认由附近的路径、行号与原文支持；【作者推断】明确标出源码没有直接说出的解释。源码注释里的原因、收益和实验记录会归属为“注释说的”，不当作本次实测结果。

公开版保留承重短引和完整源码区间，英文、标点与保留行不改。省略标记给出缺省段的精确行号；只作存在性旁证的块改为原文指针。完整原文与钉版镜像见出版说明。五行以内直接展示，较长引文默认折叠。构建特性和远端开关的存在不证明它们在某个发行包中开启。

信源边界

唯一代码信源是 2026-03-31 sourcemap 事件的备份源码树。调研没有借用外部源码分析，没有运行这棵泄露源码、连模型 API 或复现注释中的实验。产品版本无法由构建宏 MACRO.VERSION 确定（constants/system.ts:73-95）。分类器缺失的文本模板、外部 sandbox-runtime 的内部实现和未展开的压缩实验分支不属于已经审过的实现。

书中的文本要求、实际执行分支和服务端行为分别表述。读提示词时关注模型被要求做什么；读判定代码时关注哪个条件返回什么；服务端承诺仍按客户端注释或提示词的说法引用。各卷开头再说明该卷的证据边界，正文仅在具体歧义处提醒。

目录

目录按提示词装配、行为引导、工具协议、权限安全、上下文与记忆五卷排列，16章已经写齐。章节按论证顺序阅读；前后章与正文中的交叉链接使用本地 HTML，不需要联网。查具体名词可用术语索引。

内部标识约定

USER_TYPE 是内部用户分层环境变量，'ant' 为其内部取值之一（constants/prompts.ts:204-213）。引文原样保留，后文用内部用户等中性称呼；功能代号只用于描述代码门控，不据此推断发布计划或组织含义。
